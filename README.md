# Lists

This is a personal project that I am currently developing.

It is a full stack web application for you to track, rate, review, and make lists
of various different media (currently albums and movies).

# Motivation

I have previously used a few different apps for rating and tracking media, some
of the main ones are:
- [Letterboxd](https://letterboxd.com)
- [Rate Your Music](https://rateyourmusic.com)
- [JustWatch](https://justwatch.com)

I would also use the notes app on my phone, but that wasn't ideal, so I decided
to make this website to fulfill all my requirements.

# Upcoming Features

- More social elements.
- Games and TV shows
- TV show tracking (keeping track of what episode you are on)
